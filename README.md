# Final Exam Reviewer

Static GitHub Pages reviewer for Parallel and Distributed Computing.

## Contents

- Prelim Exam Set A and Set B from the existing live reviewer
- Recent 50-question final quiz split into Quiz Set A and Quiz Set B
- Combined Prelim Exam mode
- Combined Quiz of Everything mode, including prelim, Week 3, module-finals, and recent quiz banks
- Study guide, full notes explorer, glossary, and comparison tables

This site is designed to be served directly from the repository root with GitHub Pages. No build step or GitHub Actions workflow is required.
